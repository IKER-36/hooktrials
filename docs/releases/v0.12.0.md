# HookTrials v0.12.0

This release makes it easier to validate a live integration, notify your team and keep useful
evidence when something fails.

## Added

- Check a webhook destination before sending traffic. HookTrials validates reachability and the
  delivery contract without sending a payload.
- Send an explicit, synthetic test event through a live route and inspect the recorded result.
- Configure incident notifications for Discord or any compatible webhook. Choose whether to notify
  for monitor incidents, webhook delivery incidents, or both, and for opened or recovered events.
- Download redacted evidence as JSON or Markdown for sharing and troubleshooting.

## Improved

- Guided Demo setup and cleanup are isolated per account, so a demo cannot overwrite another run.
- Empty, error and retry screens now explain the next useful action instead of leaving a blank panel.
- Alert destinations remain write-only and incident notifications never include captured payloads,
  credentials or authentication headers.

## Safety note

Synthetic tests can reach the destination you configure. Use a staging endpoint or an idempotent
handler when trying a new route for the first time.
