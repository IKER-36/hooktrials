# HookTrials v0.12.1

This release makes incident notifications easier to configure and improves action clarity across
the dashboard.

## Improved

- Discord and generic webhook alerts are now shown at the top of Operations and can be opened
  directly from Monitoring.
- Action controls for monitors, webhook routes, operations and public status pages now have a
  consistent button treatment with clear hover and disabled states.
- Public status controls and monitoring actions remain readable in dark mode.
- The landing header keeps its navigation and account actions aligned at wider desktop sizes and
  switches to the compact menu only when the full navigation no longer fits.

## Fixed

- Newly created alert channels no longer appear hidden below the operational history.
- Dark-mode action controls no longer fall back to bright light surfaces.
