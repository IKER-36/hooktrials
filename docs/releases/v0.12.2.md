# HookTrials v0.12.2

This release makes the dashboard easier to navigate by giving every screen the same name as the
menu entry that opens it.

## Improved

- Every page now carries the exact title shown in the navigation. Control Center, Failure scenarios,
  Guided demo and Documentation no longer arrive under a different name.
- Control Center keeps its own title at all times and shows the selected route just beneath it,
  instead of replacing the page name with the route name.
- Page headings no longer repeat the breadcrumb directly above them, which leaves more room for
  content on every screen.
- Operations and Monitoring panels are named after what they hold: Incident timeline, Dead-letter
  inbox, Alert audit, All integrations, Status pages and Recent checks.

## Fixed

- Delete controls for trial endpoints, monitors, scenario steps and status pages are now clearly
  marked as destructive in both light and dark themes. They previously looked identical to the
  ordinary actions beside them.
