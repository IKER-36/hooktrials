# HookTrials v0.12.3

This release makes the dashboard easier to scan, understand and use during an incident.

## Improved

- Control Center surfaces live delivery activity and retry timelines earlier, before configuration
  details.
- Operations opens on incidents, dead letters and recent activity, with alert configuration kept
  available below the evidence.
- Monitoring is split into clearer areas for integrations, monitor details, setup and public status
  pages.
- Recent checks show the latest retained history and explain how many checks are kept.
- The route selector in Control Center is explicitly labelled, and endpoint rows explain where they
  open next.
- Actions across the dashboard now share consistent primary, secondary, danger and quiet states,
  including visible focus, disabled and busy feedback.
- Wide layouts use a centred reading width with clearer spacing and less repeated content.

## Fixed

- Removed repeated headings and duplicate integration rows.
- Destructive actions no longer look like ordinary actions.
- Monitor history no longer grows without a visible limit.
