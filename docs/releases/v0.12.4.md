# HookTrials v0.12.4

## security-control

- Protected captured webhook metadata and improved redaction in logs and event views.
- Added endpoint token rotation so a leaked URL can be replaced without recreating the route.
- Added safer forwarding rules for authentication and other sensitive headers while preserving
  provider signatures for destination verification.
- Added configurable monitor limits and safer manual-check throttling for shared installations.
- Updated runtime dependencies and container defaults for a safer installation.
