# HookTrials v0.13.0

## Safe self-hosted updates

- Added release-aware self-hosted updates with `./hooktrials update --release vX.Y.Z`.
- Updates create a protected PostgreSQL backup before rebuilding containers.
- Migrations and Compose health checks are waited on before an update is reported complete.
- Failed source or container updates restore the previous checkout and print the backup needed for
  database recovery.
- Added operator guidance for clean checkouts, rollback and external-access verification.
