# HookTrials v0.14.0

## Incident Center

- Filter incidents by open, recovered or awaiting acknowledgement.
- Acknowledge an incident from Operations and keep the ownership timestamp with the record.
- Add an operator note for handoffs and investigation context.
- See the number of open incidents that still need acknowledgement in the operations summary.
- Keep incident recovery evidence and outgoing alert delivery audit separate.

The API and self-hosted database migration are included in the release. Existing incidents remain
unchanged and the new triage fields are optional.
