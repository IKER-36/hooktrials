# HookTrials v0.15.1

## Expanded provider starters

Webhook Hub now gives you more ready-to-review starting points when moving an integration behind
HookTrials:

### Added

- GitLab: event, webhook UUID and token header contract.
- Linear: event, delivery and signature header contract.
- HubSpot: signature and request-timestamp header contract.
- Provider choices are available both when creating a live connection and when applying a route
  contract preset later.

### Improved

- Safe test events include representative headers for the new providers, so you can inspect the
  complete request path before switching real traffic.
- Provider metadata remains visible when reopening a route, making a mixed integration workspace
  easier to scan.
- The interface distinguishes native signature verification from contract-only validation, so the
  protection level is clear before activation.

### Fixed

- Reopening or listing a live route no longer falls back to a generic provider label when it uses one
  of the extended starters.

Native cryptographic verification remains available for Stripe and GitHub. Always review the
provider's own secret and delivery requirements before accepting production traffic.
