# HookTrials v0.15.2

## Complete Linear starter headers

This patch completes the Linear provider starter added in `v0.15.1`.

### Improved

- Linear contract presets now include event, delivery, signature and timestamp headers.
- Safe Linear test events carry a representative timestamp for clearer request inspection.
- New connections and existing route presets use the same complete header contract.

### Fixed

- Linear starter validation no longer omits `Linear-Timestamp`.

No existing delivery mode, retry or signature-verification behaviour changes.
