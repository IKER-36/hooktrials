# HookTrials v0.16.0

## Added

- Verify your email address after creating an account.
- Request a fresh verification link when an unverified account tries to log in.
- Recover access with a single-use password reset link.
- Receive welcome and password-change confirmation messages.
- New verification, recovery and password-change screens with clear, accessible feedback.

## Improved

- Account emails use a responsive HookTrials design with the product logo and dark green visual
  language.
- Every account email includes a plain-text alternative for better compatibility.
- Verification and reset links are hashed, expire automatically and can only be used once.
- Password reset requests do not reveal whether an email address is registered.
- Existing sessions are invalidated after a password change.

## Fixed

- Expired or reused account links now return a clear recovery state instead of a silent failure.
- Cloud registration can enforce email verification when transactional email is configured.

Self-hosted installations keep email optional by default. Configure a verified Maileroo sending
domain to enable the same account-security flow.
