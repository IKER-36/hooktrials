# HookTrials v0.16.1

## Added

- Control Center now includes a short activation path for new workspaces: start with a safe Trial,
  observe the first delivery, connect a real Webhook Hub route, add a monitor and review Operations.
- Every step links to the right screen and is marked **Proven** when HookTrials can see the matching
  workspace evidence.
- The activation guide follows the selected English or Spanish interface language.

## Improved

- Progress is based on real workspace state rather than a manual checklist, so it remains accurate
  when you return to an existing project.
- Email delivery diagnostics provide a bounded provider response and reference identifier while
  keeping recipients, links and secrets out of logs.
- The product package version now matches the published release line.

## Fixed

- A temporary failure in one supporting data source no longer prevents the Control Center from
  rendering the rest of the workspace.

No action is required for existing installations.
