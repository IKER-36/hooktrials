# HookTrials v0.17.0

## Added

- Protected and observed destinations now receive stable HookTrials delivery headers:
  `x-hooktrials-event-id`, `x-hooktrials-delivery-id` and `x-hooktrials-delivery-attempt`.
- Route Control offers Fast, Balanced, Patient and Custom retry profiles.
- Delivery history keeps duplicate provider attempts, automatic retries and manual replays distinct.

## Improved

- Retry profiles make attempt limits and exponential backoff easier to understand before a route is
  enabled.
- `Retry-After` remains respected while the configured maximum delay remains the safety boundary.
- HookTrials-owned delivery identity headers take precedence over custom headers, keeping downstream
  idempotency correlation trustworthy.

## Fixed

- Destinations no longer need provider-specific logic to identify the same event across retries.
- Observe responses expose the event and delivery identifiers needed for trace correlation.

Existing routes keep their saved retry settings. No migration or manual action is required.
