# HookTrials v0.18.0

## Added

- Create scoped API keys from **Resources → API keys** with separate read and write permissions.
- Run a synthetic Observe or Protect check from CI with `hooktrials-run`.
- Export redacted JSON or Markdown evidence from CI with `hooktrials-evidence`.
- Copy a new key once, inspect its prefix later and revoke it independently from other keys.

## Improved

- Automation uses explicit permissions so a read-only pipeline cannot trigger a delivery.
- Synthetic runs return a stable event ID and destination timing for CI summaries.
- The dashboard and public documentation explain safe storage, rotation and least-privilege usage.

## Fixed

- Revoked, invalid or under-scoped automation credentials are rejected before the requested action.
- CI evidence exports use the same redacted boundary as dashboard downloads and public evidence
  links.

Existing installations apply the database change during the normal update process. No route or
session recreation is required.
