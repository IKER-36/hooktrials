# HookTrials v0.18.1

## Improved

- Release images now use a deterministic AMD64 build target for the managed deployment path.
- Publishing has an explicit time limit, making stalled builds fail visibly instead of waiting
  indefinitely.
- New installations receive the same tested server and dashboard images as the current product.

## Fixed

- Prevented dependency-installation hangs during image publication caused by emulated targets.
- Kept the existing dashboard, API, CLI and self-hosted workflows unchanged.

No account, route, API key or database action is required after updating.
