# v0.21.0 — Account security and settings

HookTrials now gives account owners a safer way to protect access and keep their profile current.

## Added

- **New-account email verification** sends a single-use verification link after registration and
  keeps the new account outside the dashboard until the address is confirmed.
- **Safe migration for existing accounts** preserves access for accounts created before this
  release. Existing users do not need to verify again just to continue working.
- **Account settings** are available by selecting your profile in the dashboard sidebar. Update your
  display name, profile photo URL and sign-in details without leaving the workspace.
- **Staged email changes** send a confirmation link to the new address before it replaces the current
  login email.
- **Password changes** require the current password, rotate the session and sign out other active
  sessions. A security notification is sent after the change.
- **API access shortcut** links account settings directly to scoped API-key management.

## Improved

- Verification, recovery and email-change links remain single-use and expire automatically.
- Password and email changes are rate-limited and never expose credentials or token values.
- Profile images use HTTPS URLs and fall back to the account initials when no image is configured.

## Upgrade note

The update adds an additive account migration. Existing users, workspaces, routes, monitors, API
keys and evidence remain intact. New registrations require a verified email when the installation has
email verification enabled.
