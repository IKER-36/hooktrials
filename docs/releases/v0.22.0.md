# v0.22.0 — Route lifecycle and workspace Home

HookTrials now gives the workspace a clear starting point and a connected path from route setup to
operational recovery.

## Added

- **Workspace Home** summarizes live routes, Trial endpoints, monitors, incidents, recoveries and
  recent evidence in one read-only view.
- **Route journey** in Control Center links the selected route's setup, traffic evidence, monitoring
  and recovery steps.
- Home includes prioritized next actions and shortcuts to Webhook Hub, Monitoring, the Trial Lab and
  Operations.

## Improved

- Home is now the default workspace entry point, while Control Center focuses on one route's full
  evidence and retry timeline.
- Links between route surfaces preserve the selected endpoint and open the relevant module directly.
- The new overview and route journey remain usable on desktop and mobile layouts.

## Fixed

- `/app` no longer presents route-detail content without a route context.
- Invalid route links now show a clear way back to the endpoint inventory.
- Monitoring and Operations targets can be opened directly from the selected route journey.

No account, route, monitor or evidence migration is required.
