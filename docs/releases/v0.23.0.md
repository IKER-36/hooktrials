# v0.23.0 — Workspace telemetry

Home now gives operators a visual summary of the resources and evidence that matter most.

## Added

- See the current health mix of live routes and monitors in one compact view.
- Compare monitor availability with each monitor's configured target over the last 24 hours.
- Keep recent check and protected-recovery counts beside the visual telemetry.

## Improved

- Home keeps charts, next actions, live routes and recent activity in one consistent workspace.
- The new visualizations use the same status language and surfaces as the rest of HookTrials.
- The layout remains usable on narrow screens and scales to larger workspaces without hiding context.

## Fixed

- Empty monitoring windows now explain what must happen before a chart can show meaningful data.
- Users who prefer reduced motion no longer see entrance animation in the telemetry area.

No migration or reconfiguration is required.
