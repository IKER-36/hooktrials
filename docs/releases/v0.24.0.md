# v0.24.0 — Webhook Hub operations

HookTrials now gives real webhook connections a clearer path from provider setup to the first
verified delivery.

## What’s new

- Preview the inbound contract for the selected provider before creating a connection.
- Copy a ready-to-run `curl` smoke test immediately after creating a live route.
- Filter live connections by all, paused or needs-attention status.
- See the latest delivery state and timestamp directly in the connection list.
- Keep provider setup, destination validation and first-event actions in one guided flow.

## Improvements

- Live evidence refreshes automatically while the Webhook Hub is open.
- Loading and connection-error states explain when the latest operational data is not available.
- The dashboard no longer exposes a separate Audit history destination; redacted operational history
  remains part of Operations.
- Narrow screens keep route status and actions visible without requiring desktop navigation.

Existing accounts, routes, monitors, incidents and evidence continue to work without reconfiguration.
