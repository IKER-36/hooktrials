# v0.25.0 — Evidence and reports

HookTrials now has a dedicated place to understand recorded delivery events and share recovery
proof safely.

## Added

- Browse Evidence & reports from Resources with search, route filters and report-state filters.
- Read an explainable score, outcome, impact, duration and complete attempt-to-delivery timeline.
- Export a selected report as redacted JSON or Markdown.
- Create a temporary 24-hour link for a safe handoff without payloads, credentials or destination
  URLs.

## Improved

- Event evidence is available as a focused workspace instead of being hidden inside a single
  inspector.
- Loading, empty, filtered and last-known states make report availability explicit.
- Use Open route control to continue from a report into the route's operational workflow.

## Fixed

- Audit history is no longer shown as a separate dashboard destination. The old URL redirects to
  Operations so saved links keep working.

No account or data migration is required.
