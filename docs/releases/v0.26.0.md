# v0.26.0 — Command palette and faster navigation

HookTrials now includes a keyboard-first command palette for moving through the workspace and
running common actions without hunting through the sidebar.

## Added

- Open the palette from the context-bar search control or with **Cmd/Ctrl + K**.
- Search dashboard modules, account settings and workspace actions by name or keyword.
- Use arrow keys, Home/End and Enter to navigate and run a result.
- Switch theme, open the product tour, refresh workspace data and change sidebar density from the
  same palette.

## Improved

- Results are grouped by workspace area and include a short explanation of each destination or
  action.
- Focus remains inside the dialog until it closes, with Escape and backdrop click support.
- English and Spanish labels are available, including keyboard hints and empty-search guidance.
- The compact search trigger remains usable on smaller screens.

## Fixed

- Empty searches no longer allow keyboard selection to move past the available result set.
- Refreshing from the palette now reports errors through the normal dashboard banner.
- The former standalone Audit history tab remains removed; older `/app/audit` links still open
  Operations.

No account, route, monitor or database migration is required.
