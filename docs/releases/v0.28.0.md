# v0.28.0 — A shared visual system for the workspace

The dashboard now presents its operational modules with one consistent page composition. Titles,
supporting context and actions stay in predictable positions, making it faster to understand a
screen and choose the next safe action.

## Added

- Shared page heading treatment across Home, Webhook Hub, Monitoring, Operations, Evidence,
  Reliability and resource screens.
- Responsive action layout that stacks cleanly on narrow screens.
- Consistent focus treatment for keyboard users across page controls.

## Improved

- Trial endpoints, Failure scenarios, Guided demo, Documentation, API keys, Workspace and Account
  settings now follow the same heading rhythm as the core operational modules.
- Health and evidence summaries read as a single operational strip instead of a collection of
  unrelated surfaces.
- Light and dark themes keep the same hierarchy, button contract and reduced-motion behaviour.
- Audit entries remain available in Operations without exposing a duplicated Audit history tab.

## Fixed

- Corrected inconsistent spacing and action alignment between dashboard pages.
- Prevented long page copy from displacing actions on smaller viewports.
- Preserved visible keyboard focus in dense lists, selectors and action areas.

No API, database or account migration is required.
