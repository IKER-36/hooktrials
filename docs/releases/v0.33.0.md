# v0.33.0 — Account session controls

Released 1 August 2026.

## New

- Review active browser sessions from **Account settings**, including last use and expiration.
- Sign out all other sessions after using a shared device or rotating account access.
- Keep account profile, email verification, password and session controls together in one security
  area.

## Improved

- Session activity is refreshed periodically so the list reflects recent use without exposing
  device details or network addresses.
- Password changes and password recovery continue to invalidate other sessions while preserving the
  session used to complete the change.
- Workspace roles, invitations and scoped API keys remain separate from browser sessions, making
  team access easier to reason about and rotate.

## Fixed

- Viewer and operator accounts can now manage their own profile, password and sessions without
  receiving workspace-configuration permissions.
- Revoking a session immediately removes its server-side token; the browser must authenticate again.

See [Account security](../account-security.md) for the complete guide.
