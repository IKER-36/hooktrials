# v0.33.1 — Self-host diagnostics

Released 1 August 2026.

## New

- Run `./hooktrials doctor --deep` for a read-only self-host preflight.
- Check Compose service state, API health, installation metadata, disk space and local PostgreSQL
  backup presence from one command.

## Improved

- Operator handoffs now have a clear diagnostic command that does not print runtime secrets,
  cookies, payloads or credentials.
- The existing update, backup and rollback workflow remains unchanged and keeps data volumes
  intact.

## Fixed

- The CLI help now documents both external-access and deep diagnostic modes consistently.

See [Self-hosting](../self-hosting.md) and [CLI and CI](../cli-and-ci.md) for the operator workflow.
