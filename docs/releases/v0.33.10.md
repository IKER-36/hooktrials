# HookTrials v0.33.10

Released 1 August 2026.

## Added

- Webhook Hub route filters can now be shared with all live connections, routes needing attention or
  paused routes already selected.
- Monitoring can reopen the selected monitor from a direct link, making handoffs between operators
  more precise.

## Improved

- Refreshing a filtered Webhook Hub view keeps the same operational context instead of returning to
  the default list.
- Refreshing Monitoring keeps the selected inventory item and its detail view when it still exists.
- Removed or invalid monitor links recover gracefully by selecting the first available monitor.
- Shared links contain navigation state only. Payloads, credentials and destination URLs remain out
  of the browser address.
- The inventory/detail workflow remains keyboard-accessible and usable on narrow screens.

No database migration or user action is required.
