# HookTrials v0.33.11

Released 1 August 2026.

## Added

- Home reliability windows can now be shared as `24 hours`, `7 days` or `30 days` views.
- A shared Home link opens with the same telemetry period already selected.

## Improved

- Refreshing Home keeps the selected period instead of silently returning to 24 hours.
- Chart headings, reliability summaries and check counts identify the active window together.
- Changing the window updates the dashboard without a full page reload or a noisy history entry.
- Invalid window values fall back safely to the default 24-hour view.
- Existing metric links, mobile layout and reduced-motion behavior remain unchanged.

No database migration or user action is required.
