# HookTrials v0.33.12

Released 1 August 2026.

This release makes account self-service and public status pages easier to operate, while tightening
the visual and keyboard feedback of compact dashboard controls. Existing workspaces and data remain
compatible.

## Added

- **Resend verification email** is available from **Account settings** when an account still needs
  verification. The action confirms that the request was accepted and points you to the inbox and
  spam folder.
- Public status pages now have a **Refresh** control for an immediate update.
- An unavailable public status response includes a **Retry** action so visitors can recover from a
  temporary network problem without reloading the entire page.

## Improved

- Public status pages keep their normal 30-second automatic refresh after a manual refresh or retry.
- Refreshing status data shows a clear busy state and prevents duplicate requests while the latest
  checks are being loaded.
- Compact dashboard actions use the same readable hover, pressed and keyboard-focus treatment in
  light and dark themes, including touch-friendly target sizes.
- Scenario choices use a restrained selected surface instead of a bright left-hand focus rail, so
  the active choice remains clear without competing with the content.

## Fixed

- Public status error states now provide a direct next step instead of ending in a dead end.
- Small delivery and navigation controls remain legible when selected, focused or pressed.
- Verification and account-security guidance is shown next to the relevant action rather than
  requiring users to infer what happened from a generic notification.

## Upgrade note

No database migration or manual configuration change is required. Existing active accounts continue
to work normally; verification is enforced only for accounts already marked as requiring it.
