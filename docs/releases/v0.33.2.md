# v0.33.2 — Workspace visual polish

Released 1 August 2026.

## Added

- Home now presents resource totals, health state and recovery signals through a consistent metric
  strip that remains readable on narrow screens.
- Route changes have a short, calm transition that makes navigation easier to follow without
  delaying the next screen.
- Mobile navigation keeps the most-used destinations visible and groups the rest under **More**,
  so every workspace module remains reachable without horizontal scrolling.

## Improved

- Buttons, fields, panels and list rows now share the same spacing, focus treatment, border rhythm
  and touch-target size across the dashboard.
- Home telemetry charts use the same semantic colors as the rest of the workspace and animate only
  when the device allows motion.
- Dark and light themes keep interactive surfaces legible, including hover, focus and selected
  states.

## Fixed

- The mobile navigation bar no longer wraps or hides destinations on compact screens.
- Metric and chart sections keep a stable layout while data loads, avoiding sudden page jumps.
- Reduced-motion preferences now disable route and chart movement while preserving the information.

No database migration or user action is required.
