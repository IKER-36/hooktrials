# v0.33.3 — Operational workspace polish

Released 1 August 2026.

## Added

- Integration inventory rows now include a visible **Open** action and a descriptive accessible
  label.
- The monitor editor keeps keyboard focus inside the dialog and restores it after closing.
- Control Center’s empty workspace includes a clearer start marker and a responsive first-run
  layout.

## Improved

- Inventory and monitor selection rows share the same hover, focus and selected behavior in both
  themes.
- Control Center summary links have a consistent control shape and touch target.
- The first-run instructions remain readable on mobile without losing the primary action.

## Fixed

- Inventory actions no longer appear as unstyled text.
- Keyboard users can no longer tab behind the monitor editor while it is open.
- The Control Center state label follows the selected language in the same way as other workspace
  copy.

No database migration or user action is required.
