# v0.33.4 — Reliability workspace coherence

Released 1 August 2026.

## Added

- Failure scenarios and Guided Demo now use the same page heading and action placement as the rest
  of the dashboard.
- Evidence rows include a clear **Open** affordance while retaining keyboard selection.
- Scenario library items and Evidence filters have consistent selected, hover and focus states.

## Improved

- Reliability rows present availability, latency, incidents and error-budget state in one compact
  scan line.
- Guided Demo presents its eight steps as one chronological rail with the controls alongside it on
  desktop and below it on mobile.
- Scenario editing keeps response steps and destructive actions grouped and readable at narrow
  widths.

## Fixed

- Reliability remains usable when an older or partial response does not include an error-budget
  percentage.
- Evidence, Scenario and Demo surfaces now keep their contrast and borders correct in dark mode.
- New lab headings follow the selected language.

No database migration or user action is required.
