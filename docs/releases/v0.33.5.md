# HookTrials v0.33.5

## Operational surface coherence

Webhook Hub, Monitoring, Operations and account workspaces now share the same visual language for
state, context and actions.

### Improvements

- Live webhook connections show their health, latest delivery signal and actions in one predictable
  row.
- Incident, dead-letter and alert evidence is easier to scan, with state and operator actions kept
  together.
- Public status-page entries use a compact list with clear Open, Edit, Rotate and Delete actions.
- Account and workspace headers now match the shared dashboard heading layout.
- Responsive action groups keep their order and remain usable on narrow screens.

### Fixes

- Focus and hover states now remain visible without relying on a bright background.
- Long names, hosts and messages no longer push operational controls off-screen.
- Dark mode keeps operational surfaces readable without light-theme fallback colours.

No database migration or user action is required.
