# HookTrials v0.33.7

## Actionable Home dashboard

Home now connects workspace signals with the next place to act.

### Added

- Choose a reliability window of 24 hours, 7 days or 30 days for the Home coverage view.
- Click any headline metric to open the corresponding product or operations workspace.
- See when the overview last refreshed.

### Improved

- Coverage charts and check counts now show the selected period clearly.
- Metric surfaces expose consistent hover, focus and keyboard states without changing the compact
  dashboard layout.
- The control remains usable on narrow screens and respects reduced-motion preferences.

No database migration or user action is required.
