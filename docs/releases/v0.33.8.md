# HookTrials v0.33.8

Released 1 August 2026.

## New

- Added a contextual workflow bar to the main workspaces: Home, Webhook Hub, Control Center,
  Monitoring, Operations and Evidence.
- Each workflow step opens the module responsible for that part of the reliability process.
- Added a responsive compact layout so the workflow remains useful on mobile screens.

## Improved

- The active workspace is now easier to identify without relying on the sidebar alone.
- Navigation links have consistent hover, keyboard-focus and dark-mode states.
- The workflow follows the same reduced-motion and accessibility behavior as the rest of the app.

No database migration or user action is required.
