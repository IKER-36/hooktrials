# HookTrials v0.33.9

Released 1 August 2026.

## Added

- Operations links from Home and the activity timeline now open the exact incident, delivery or
  alert that needs attention.
- Queue filters for incidents, recovery and alert delivery are preserved in the URL.
- Historical recovered deliveries open with the resolved view enabled when needed.

## Improved

- Deep links wait for live data before positioning the page, so they work reliably after refresh.
- The selected row is highlighted without hiding its healthy, warning or failure status.
- Shared links contain only safe view state and never include payloads, secrets or destination data.

No database migration or user action is required.
