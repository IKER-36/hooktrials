# HookTrials v0.34.0

This release makes HookTrials easier to understand from the first session. The dashboard is now
organized around the job you want to complete, while the optional synthetic demo stays separate
from normal integrations, monitoring and operational evidence.

## Added

- Home now starts with three explicit outcomes: **Connect a real webhook**, **Test an integration
  safely** or **Monitor a service**.
- The dashboard uses a consistent task map: **Build** for Integrations, Test Lab and Scenarios;
  **Operate** for Monitoring and Incidents & recovery; and **Prove** for Reliability and Evidence.
- Each real integration opens its own **Delivery timeline**, keeping configuration, request history,
  retries and readiness evidence attached to the resource being investigated.
- Resource APIs support an optional `scope=product|demo|all` query for clients that need to separate
  normal workspace data from synthetic demo data. Omitting it preserves the previous behavior.

## Improved

- Demo Lab is no longer a normal navigation destination. It remains available through the collapsed
  guided-example section on Home or its direct URL when a separate synthetic walkthrough is useful.
- Home metrics, integrations, scenarios, monitors, status pages, incidents, reliability and evidence
  now exclude demo-owned resources from their normal product views.
- Desktop navigation, collapsed sidebar, mobile navigation, command search, onboarding and product
  documentation use the same names and module ownership.
- The repeated cross-page workflow strip has been removed. Pages now show their own purpose, primary
  action and contextual next step without duplicating global navigation.
- The in-product guide explains when to connect real traffic, use Test Lab, monitor a dependency,
  recover an incident or retain evidence.

## Fixed

- Synthetic demo endpoints no longer inflate live-integration or Test Lab counters.
- Demo-created scenarios and public status pages no longer appear in normal product inventories.
- The old global Control Center entry no longer opens an ambiguous selected resource; it returns to
  Home, while saved endpoint-specific links continue to open the correct Delivery timeline.
- A stale demo selection no longer becomes the default product endpoint when normal resources are
  available.

No database migration or manual data cleanup is required. Existing users, integrations, endpoints,
monitors, incidents and evidence remain intact.
